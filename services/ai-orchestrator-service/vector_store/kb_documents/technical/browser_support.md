# Browser compatibility

Recommend the latest supported version of Chrome, Edge, Firefox, or Safari. Ask the customer
to disable extensions temporarily and retry in a private window. Capture browser version and
any console-visible error only if the customer can provide it safely.

**Common ways customers describe this:** not working in Chrome; broken in Safari; page looks wrong in Firefox; buttons won't click; browser not supported; works on phone but not on browser.

**Additional common phrasings (from a broader synthetic support-ticket dataset covering similar issue types):** login screen is blank in one specific browser; stuck in a sign-in loop on Chrome; page layout looks broken or overlapping in Firefox.
