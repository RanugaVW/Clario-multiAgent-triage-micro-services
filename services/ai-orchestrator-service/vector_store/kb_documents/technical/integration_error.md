# Integration connection errors

Verify the integration is enabled and the customer has the required permissions. Ask them to
reconnect the integration and note any displayed error code. Do not request external service
passwords or API secrets in a ticket.

**Common ways customers describe this:** integration won't connect; third-party app disconnected; sync with external service failed; permission error connecting; connection keeps dropping; getting an API error code; can't connect my account to [service]; integration keeps disconnecting; getting an error code when linking; sync with [third-party tool] failed; modules aren't loading and the in-browser compiler shows errors on correct code; notebook viewer shows a blank content area; can't join the live Zoom class.

**Additional common phrasings (from a broader synthetic support-ticket dataset covering similar issue types):** SSO login keeps failing; getting a 403 error when authenticating through SSO; asking for a calendar app integration.
