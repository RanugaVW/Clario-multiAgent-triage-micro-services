# Service availability

When a feature appears unavailable, check the current service-status communication before
troubleshooting the account. If there is no known incident, record the affected feature,
region if supplied, start time, and exact error message for technical triage.

**Common ways customers describe this:** site is down; feature not loading for anyone; is there an outage; service unavailable; nothing is working right now; down for everyone or just me; site is down, can't access anything right now; getting a server error; nothing is loading for me; can't continue learning; no further detail given; the continue button shows the wrong color and won't let me into the course; clicking continue learning just refreshes the page.

**Additional common phrasings (from a broader synthetic support-ticket dataset covering similar issue types):** certificate download service seems to be down; asking if there's a planned maintenance outage.
