# 03 — UI / End-to-End Testing (Planned)

**Status:** Not yet executed.

**Sample-plan equivalent:** §3.1.3 User Interface Testing.

**Scope for Clario:** browser-driven testing of the customer dashboard
(ticket submission, resolution view, 1-5 feedback rating) and the admin
console (ticket review, score overrides, judge/customer rating badges),
covering navigation, form submission, and rendering correctness. The
sample plan's tool (Selenium IDE) targets a legacy PHP app; for this
Next.js app the equivalent choice is Playwright or Cypress against a
running dev server.
