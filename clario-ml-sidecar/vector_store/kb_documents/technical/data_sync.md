# Data synchronization issues

Ask whether the affected records appear after a refresh and whether the issue occurs on web
and mobile. Record the affected record identifiers, last successful sync time, and app
version. Escalate persistent data-loss concerns immediately for technical investigation.

**Common ways customers describe this:** changes aren't syncing; data missing after refresh; out of sync between devices; records not updating; sync stuck; mobile and web show different data; changes aren't saving; my data disappeared; not showing up on my other devic; out of sync between web and mobile; recordings and notes are not visible, missed a live session and need the recording; error appears after entering my profile details; never received my certificate after finishing the course; name is spelled wrong on my certificate.

**Additional common phrasings (from a broader synthetic support-ticket dataset covering similar issue types):** quiz scores aren't syncing between mobile and web; course progress not syncing after switching devices.
