# Slow performance

For a slow or unresponsive app, ask the customer to check their connection, restart the app,
and install available updates. If the problem occurs on multiple networks after an update,
record the affected feature, timestamp, and app version for engineering review.

**Common ways customers describe this:** app is slow; page takes forever to load; everything is lagging; app is unresponsive; slow since the last update; slow even on fast wifi; app is really slow; pages take forever to load; everything is lagging; much slower than it used to be.

**Additional common phrasings (from a broader synthetic support-ticket dataset covering similar issue types):** video takes a long time to start playing; library search is very slow; logout takes a long time to complete.

**Additional common phrasings (from real public reviews of comparable LMS platforms — Udemy, Coursera, Skillshare):** platform feels slow and unoptimised, videos won't load.
