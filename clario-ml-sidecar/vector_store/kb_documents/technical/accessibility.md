# Accessibility support

For screen-reader or keyboard-navigation issues, capture the page or feature, assistive
technology, browser, and operating-system version. Offer the documented keyboard workflow
when available and route reproducible barriers to the accessibility engineering queue.

**Common ways customers describe this:** screen reader not reading the page; can't navigate with keyboard only; tab key doesn't move between fields; low contrast, hard to see; missing alt text on images; keyboard shortcuts not responding; screen reader isn't reading this right; missing alt text; focus outline not visible; screen reader isn't reading this right; missing alt text.

**Additional common phrasings (from a broader synthetic support-ticket dataset covering similar issue types):** want larger font size options; asking for closed captions in more languages; requesting a read-aloud option for course text.
