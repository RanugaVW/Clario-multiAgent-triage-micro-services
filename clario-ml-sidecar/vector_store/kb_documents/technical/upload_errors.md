# Upload failures

Confirm the file format and size meet the product limits, then ask the customer to retry on
a stable connection. If upload fails repeatedly, request the exact error text and preserve
the upload time and file type in the technical support case.

**Common ways customers describe this:** upload failed; file won't upload; upload stuck at zero percent; file too large error; wrong file format rejected; upload keeps failing; upload keeps failing; file won't upload; error when I try to submit a file; stuck at X% upload; submitted a project but it's not showing as received; can't submit the final project even after the deadline was extended.
